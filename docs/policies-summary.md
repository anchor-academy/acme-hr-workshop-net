# Policy summary (for Claude Code)
- Annual leave: 14 days (18 after 5 years). Working days only, Mon–Fri. (POL-01)
- Up to 3 working days: auto-approved if balance allows. Over 3 days: manager approval. No overlaps. (POL-02)
- Half day: AM or PM, same day, deducts 0.5. (POL-03)
- Full policies are in the `Policies` table (POL-01 … POL-15).
